Database Management

Learn how to organize, store, query, and manage application data using SQL and SQLite.

01

Database Fundamentals

A database organizes information into tables. Each table contains rows and columns. A primary key uniquely identifies each record.

Table Structure Example 
CREATE TABLE students (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    age INTEGER
);

Explanation: Explanation: Each row represents a student. The id column is the primary key, while each column stores a specific type of information.

02

SQL Fundamentals

SQL (Structured Query Language) is used to communicate with relational databases.

SQL Query Example 
SELECT name, email
FROM students
WHERE age >= 18
ORDER BY name ASC;

Explanation: Explanation: SELECT chooses columns, WHERE filters records, and ORDER BY sorts the results.

03

SQLite with Python

SQLite is a lightweight database engine that stores data in a local file. Python includes the sqlite3 module for working with SQLite.

Python and SQLite Example 
import sqlite3

connection = sqlite3.connect("school.db")

connection.execute(
    "CREATE TABLE IF NOT EXISTS students ("
    "id INTEGER PRIMARY KEY, "
    "name TEXT NOT NULL)"
)

connection.commit()
connection.close()

Explanation: Explanation: connect() opens the database, execute() runs SQL, and commit() saves database changes.

04

CRUD Operations

CRUD stands for Create, Read, Update, and Delete. These are the four basic operations used to manage stored records.

CRUD with Parameterized Queries 
import sqlite3

connection = sqlite3.connect("school.db")

# Create
connection.execute(
    "INSERT INTO students (name) VALUES (?)",
    ("Alex",)
)

# Read
rows = connection.execute(
    "SELECT id, name FROM students"
).fetchall()

# Update
connection.execute(
    "UPDATE students SET name = ? WHERE id = ?",
    ("Jordan", 1)
)

# Delete
connection.execute(
    "DELETE FROM students WHERE id = ?",
    (1,)
)

connection.commit()
connection.close()

Explanation: Explanation: Parameterized queries use placeholders such as ?. They keep data separate from SQL instructions and are safer than building queries through string concatenation.

05

Relationships and JOIN

Relational databases connect tables using keys. A one-to-many relationship allows one record to be associated with multiple records in another table.

Foreign Key and JOIN Example 
CREATE TABLE courses (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL
);

CREATE TABLE enrollments (
    id INTEGER PRIMARY KEY,
    student_id INTEGER,
    course_id INTEGER,
    FOREIGN KEY (student_id) REFERENCES students(id),
    FOREIGN KEY (course_id) REFERENCES courses(id)
);

SELECT students.name, courses.title
FROM enrollments
JOIN students ON students.id = enrollments.student_id
JOIN courses ON courses.id = enrollments.course_id;

Explanation: Explanation: Foreign keys connect related records. JOIN combines information from multiple tables in one query.
