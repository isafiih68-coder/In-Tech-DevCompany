Backend Development

Learn to build application systems using Python, Flask, APIs, and databases.

01

Python — Programming Fundamentals

Python is a programming language used to build application logic.

Python Example 
name = "In.Tech"
language = "Python"

print("Welcome to", name)
print("Learning language:", language)

Explanation: variables store data that can be reused in a program.

02

Flask — Creating Routes

Flask is a Python framework for building web applications.

Flask Example 
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Welcome to In.Tech"

if __name__ == "__main__":
    app.run(debug=True)

Explanation: @app.route("/") defines the main URL of the application.

03

API — Sending Data

APIs allow applications to provide data in a format that other systems can read.

JSON Response Example 
{
    "company": "In.Tech",
    "backend": "Python Flask",
    "database": "SQLite",
    "status": "active"
}

Explanation: JSON organizes data using key-value pairs.

04

Database — Storing Data

Databases are used to store and manage application information.

SQLite Example 
import sqlite3

connection = sqlite3.connect("devcompany.db")

connection.execute("""
    CREATE TABLE IF NOT EXISTS users (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL
    )
""")

connection.commit()
connection.close()

Explanation: SQLite stores data in a file-based database.
