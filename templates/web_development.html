Web Development

Learn to build website interfaces using HTML, CSS, and JavaScript.

01

HTML — Website Structure

HTML structures page elements such as headings, paragraphs, images, and links.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to In.Tech</h1>
    <p>I am learning Web Development.</p>
</body>
</html>

Explanation: h1 creates the main heading, while p creates a paragraph.

02

CSS — Website Styling

CSS controls the colors, sizes, spacing, and layout of HTML elements.

CSS Example 
body {
    font-family: Arial, sans-serif;
    background: #F7F9FF;
    color: #243047;
}

h1 {
    color: #315EFB;
    text-align: center;
}

Explanation: color sets the text color, while background sets the background color.

03

JavaScript — Website Interactivity

JavaScript allows web pages to respond to user actions.

JavaScript Example 
const button = document.querySelector("#tombol");

button.addEventListener("click", function () {
    alert("Hello from In.Tech!");
});

Explanation: addEventListener runs a function when a user clicks.
