01

Software Engineers Fundamentals

Software engineers applies structured methods to designing, developing, testing, and maintaining software systems.

Simple Problem-Solving Example 
def calculate_total(price, quantity):
    if price < 0 or quantity < 0:
        raise ValueError("Values cannot be negative")

    return price * quantity


total = calculate_total(25, 3)
print("Total:", total)

Explanation: Explanation: Breaking a task into a reusable function makes the program easier to understand, test, and maintain.

02

Software Development Life Cycle

The Software Development Life Cycle (SDLC) provides a structured process for creating and maintaining software.

SDLC Stages 
# 1. Planning
# Define goals and requirements.

# 2. Analysis
# Understand user and system needs.

# 3. Design
# Plan the architecture and interface.

# 4. Development
# Write and organize the code.

# 5. Testing
# Check functionality and fix issues.

# 6. Deployment
# Release the application.

# 7. Maintenance
# Improve and update the software.

Explanation: Explanation: SDLC helps teams organize work into clear stages, from initial planning through long-term maintenance.

03

Git and GitHub Fundamentals

Git tracks changes in source code. GitHub provides a platform for hosting repositories and collaborating with other developers.

Basic Git Workflow 
# Create a repository
git init

# Check changed files
git status

# Stage changes
git add .

# Save a version
git commit -m "Add learning materials"

# Review commit history
git log --oneline

# Create a development branch
git branch feature-learning

Explanation: Explanation: A commit records a version of your work. Branches allow you to develop features separately from the main branch.

04

Testing and Debugging

Testing checks whether software behaves as expected. Debugging helps developers identify and correct problems.

Python Unit Test Example 
import unittest

def add_numbers(a, b):
    return a + b

class TestMathFunctions(unittest.TestCase):
    def test_add_numbers(self):
        self.assertEqual(add_numbers(2, 3), 5)

if __name__ == "__main__":
    unittest.main()

Explanation: Explanation: The test verifies that add_numbers(2, 3) returns 5. Automated tests help detect unexpected changes.

05

Secure Coding Fundamentals

Secure coding helps protect application data through validation, safe database access, careful secret management, and appropriate permissions.

Input Validation Example 
def register_user(username, email):
    username = username.strip()
    email = email.strip()

    if not username:
        raise ValueError("Username is required")

    if "@" not in email:
        raise ValueError("A valid email is required")

    return {
        "username": username,
        "email": email
    }

Explanation: Explanation: Validate user input before processing it. Keep credentials outside source code, use password hashing, and apply only the permissions an application needs.
