# Contributing to In.Tech

Thank you for your interest in contributing to In.Tech.

## Getting Started

1. Read the project README.
2. Fork or clone the repository.
3. Create and activate a Python virtual environment.
4. Install dependencies using `python -m pip install -r requirements.txt`.
5. Configure local environment variables using `.env.example`.
6. Run the application locally using `python app.py`.

## Contribution Guidelines

- Preserve existing application functionality.
- Keep application interfaces and documentation in English.
- Follow existing project conventions.
- Keep changes focused and explain their purpose.
- Test affected functionality before submitting changes.
- Never include credentials, secret keys, private databases, or personal data.
- Do not commit `.env`, `instance/`, logs, or private backups.

## Pull Requests

Please include:

- A clear description of the change.
- The reason for the change.
- Tests performed.
- Relevant screenshots or terminal output when useful.

Keep each pull request focused on a specific improvement.
